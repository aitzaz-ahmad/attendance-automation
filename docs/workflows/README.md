# Workflows

This directory contains repository workflow documents used by humans and AI agents.

These documents define operational process boundaries for issue execution,
branching, commits, validation, and pull request preparation.

## Workflow Documents

- `issue-lifecycle.md` — GitHub issue lifecycle and status expectations.
- `branch-strategy.md` — branch naming and branch flow.
- `commit-conventions.md` — commit message format and commit hygiene.
- `validation-gates.md` — required validation commands and reporting expectations.

## Usage

Load only the workflow document relevant to the current task.

Do not recursively load all workflow documents unless the task explicitly
requires a full workflow review.

## Scope

Workflow documents describe process. They should not duplicate architecture,
implementation, or planning contracts.
